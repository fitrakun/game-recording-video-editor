# Third-party components and references

This repository distributes its original instructions and Python helpers under MIT. It does not bundle FFmpeg, Python packages, models, voices, fonts, game footage, or other Agent Skills.

- **FFmpeg/libass/libx264:** installed separately. Their build-specific license obligations apply to redistribution of those binaries; they are not included here.
- **NumPy and Pillow:** installed through `requirements.txt`; their respective licenses apply.
- **VoiceStudio:** an optional external application with its own license and model conditions. No VoiceStudio source is copied here.
- **VoxCPM:** an optional runtime/model from OpenBMB. Its current code/model terms and those of dependencies apply. No model weights or VoxCPM implementation is bundled.
- **content-principles:** an optional separate skill by Remy Gaskell / aiwithremy, linked in the documentation. Its text is not included or relicensed. The public edition replaces a prior personal-use snapshot with an original task-specific scripting guide.

Users supply authorized footage and audio. A software license does not grant rights to someone else's game assets, recordings, font files, or voice likeness.
