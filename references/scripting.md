# Writing around the actual gameplay

This is an original practical guide for this skill. It does not reproduce the separately published [content-principles skill by Remy Gaskell / aiwithremy](https://github.com/aiwithremy/content-principles). Users can install that upstream skill separately and request both together.

Start with the footage, not a reusable script outline. Identify the moment worth showing, its visible proof, and the smallest amount of context someone needs to enjoy it. For a tiny object discovery, viewers need to understand the target, see the search narrow, and recognize the object when it appears. For a narrative surprise, preserve the lines that make the reveal meaningful.

Choose an opening that belongs to this recording. A visible unusual scale, sudden reversal, or difficult-to-spot detail can create interest immediately. Confirm all numbers against the recording. Keep qualifiers such as “more than”; distinguish a rounded description from an exact count.

Write short conversational phrases someone can understand while watching moving gameplay. Lead directly into action. A sentence earns its place by explaining a necessary detail, increasing anticipation, revealing something, or expressing the user's supported reaction. Remove general praise, repeated instructions, and narration of obvious actions that do not improve the moment.

Let the game supply evidence. A detector beep is a lead; the object appearing, being picked up, or entering the collection is the payoff. Preserve that distinction. If you invite viewers to spot an item, give them a brief fair view before adding a pointer. Do not manufacture difficulty, claim a first find without evidence, or recast an AI voice as recorded player speech.

For long quiet games, combine a few visually different enjoyable moments rather than keeping a long representative stretch. A machine handling hay can be a short satisfying detour, but the discovery should remain easy to follow. A short needs neither a forced cliffhanger nor a closing question when its natural payoff is strong.

Before generating audio, read the script against the selected scene windows. Trim words that make the narration rush, and adjust durations where viewers need to inspect something. Use exactly that approved text for synthesis and subtitle cues. Emphasis headlines may be shorter; subtitles retain every spoken word.
